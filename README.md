# Todo List

A simple Todo List web app built with HTML, CSS, and JavaScript.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Clear all tasks
- Track completed task count
- Display the current date
- Save tasks using localStorage
- Create recurring tasks for specific days of the week
- Automatically generate recurring tasks for the current day
- Skip individual recurring tasks
- Recurring task indicators
- Responsive layout for smaller screens

## Built With

* HTML
* CSS
* JavaScript
* Browser `localStorage`

## How to Run

Download or clone the repository and open `index.html` in a web browser.

No installation or additional dependencies are required.
